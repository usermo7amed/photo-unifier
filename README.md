# مُوحِّد الصور (Photo Unifier)

تطبيق Android لمعالجة مجموعة صور مع الحفاظ على الأصل، وحفظ الناتج في مجلد Pictures/PhotoUnifier.

## إيه الجديد في النسخة 0.2؟

- **تصنيف على الجهاز:** نموذج ML Kit العام بيطلع دلالات للصورة، وبعدها التطبيق بيربط الدلالات بمسارات المستندات والبوسترات والأماكن الداخلية والخارجية.
- **مسار منفصل لكل نوع:** الأماكن الداخلية بتاخد ضبط توازن الأبيض ورفع/ضغط الإضاءة محليًا؛ الخارجية بتحافظ أكتر على لون المشهد وبتضغط الهايلايتس؛ البوسترات بتحافظ على الألوان مع معالجة أهدى؛ والمستندات بتاخد إزالة ظل الورق على قناة الإضاءة.
- **تصحيح منظور مشروط:** المستند أو البوستر بيتقص ويتصحح منظوره فقط لما OpenCV يلاقي شكل رباعي واضح وكبير بدرجة كفاية. لو الكشف مش موثوق، الصورة بتكمل من غير قص تلقائي.
- **ذاكرة أكثر أمانًا:** تحرير موارد OpenCV وملفات الصور المؤقتة حتى مع فشل معالجة صورة.
- **اختبارات:** اختبارات وحدة لتصنيف الأنواع، واختبارات Python تركيبية لإزالة الظلال وكشف المنظور ومسارات المعالجة.

## حدود مهمة

نموذج ML Kit المضمّن هو **نموذج تصنيف عام جاهز**؛ مش نموذج مخصص اتدرّب على مجموعة صور خاصة بالمستندات والبوسترات والداخل والخارج. التطبيق بيستخدم درجات دلالية من الكلمات اللي النموذج بيتعرف عليها عشان يختار المسار. لو النموذج مش واثق أو الدلالات ضعيفة، بيرجع لمسار الصورة العامة. عشان نوصل لتصنيف أدق بجد، الخطوة التالية هي تجميع صور مصرّح باستخدامها وموسومة بالفئات الأربع، وتدريب نموذج مخصص واختباره على صور منفصلة عن التدريب.

اكتشاف الورقة وتصحيح المنظور تقنيات OpenCV تقليدية، مش ضمان نجاح لكل صورة. الورقة البيضا على خلفية بيضا أو الورقة المثنية ممكن تحتاج ضبط يدوي. وإزالة الظلال ما تقدرش تسترجع تفاصيل اتسجلت أبيض/أسود بالكامل وقت التصوير.

## البناء والاختبارات

المشروع بيستخدم Java 17 وGradle 8.7 وAndroid Gradle Plugin 8.5.2. من جذر المشروع شغّل الأمر التالي:

    gradle testDebugUnitTest assembleDebug --no-daemon --stacktrace

أو اعمل push على فرع main؛ GitHub Actions بيشغّل اختبارات Kotlin ويبني APK ويرفعه كـ Artifact باسم photo-unifier-debug.

اختبارات خوارزميات OpenCV على الكمبيوتر:

    pip install opencv-python-headless numpy
    python -m unittest discover -s tools/prototype/tests -v
    python tools/prototype/enhance.py input.jpg before_after.jpg --mode document

الأنماط المتاحة في النموذج التجريبي: auto وinterior وexterior وdocument وposter. النموذج التجريبي لا يشغّل ML Kit؛ اختيار النوع تلقائيًا موجود في تطبيق Android.

الصور اللي أطول ضلع فيها أكبر من 4096 بكسل بتتصغّر مؤقتًا لتقليل استهلاك الذاكرة. الأصلية لا يتم تعديلها.
