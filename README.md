# مُوحِّد الصور (Photo Unifier)

تطبيق أندرويد بيعالج دفعة صور بضغطة واحدة: ضبط الإضاءة والألوان وإظهار التفاصيل، مع محاولة اكتشاف الورق أو البوستر وتصحيح المنظور قبل التحسين.

## النسخة التطويرية

- اختيار مجموعة صور وحفظ النسخ المحسّنة في `Pictures/PhotoUnifier` من غير تعديل الصور الأصلية.
- خط المعالجة الحالي بيستخدم ضبط توازن أبيض محدود، وضبط إضاءة محلي، وCLAHE، وزيادة تشبع وحدّة بدرجة خفيفة.
- **تصحيح منظور تجريبي:** OpenCV بيبحث عن شكل رباعي كبير ومحدب، وبيصحح المنظور بس لما يلاقي مرشح مناسب. لو مفيش مرشح واضح، بيحتفظ بإطار الصورة الأصلي.
- الصور الكبيرة بتتصغر مؤقتًا لحد أقصى 4096 بكسل في أطول ضلع أثناء التحميل، وكشف الورق بيشتغل على نسخة أصغر لتقليل استهلاك الذاكرة.
- التعامل مع الـ Bitmap والـ Mat بيتم داخل `finally` لتقليل تسريب الذاكرة عند فشل معالجة صورة في دفعة.

> **حدود معروفة:** كشف الشكل الرباعي مش تصنيف دلالي كامل، وممكن يفوّت ورقة على خلفية مزدحمة أو يلتقط شكل مستطيل شبيه بالورق في بعض المشاهد. النسخة دي لسه ما فيهاش نموذج ML مخصص لتصنيف داخلي/خارجي/مستند/بوستر، ولا إزالة ظلال متخصصة للورق. لازم اختبارها على صور واقعية قبل اعتبار القص التلقائي آمنًا لكل الحالات.

## بناء APK

1. افتح **Actions → Build APK** في GitHub.
2. شغّل الـ workflow أو استنى تشغيله بعد Push.
3. بعد نجاح البناء، نزّل الـ Artifact باسم `photo-unifier-debug`، فك الضغط وثبّت `app-debug.apk` على الموبايل.

الـ workflow بيستخدم Java 17 وGradle 8.7.

## تجربة خوارزمية التحسين على الكمبيوتر

```bash
pip install opencv-python-headless numpy
python tools/prototype/enhance.py input.jpg before_after.jpg
```

## خطة التطوير التالية

1. تصنيف المشاهد باستخدام نموذج صور على الجهاز، مع قرار محافظ بين داخلي وخارجي ومستند وبوستر.
2. تحسين محلي مختلف حسب نوع الصورة بدل تطبيق نفس الإعدادات على الجميع.
3. إزالة ظلال الورق وتوحيد الخلفية مع الحفاظ على النص والألوان.
4. اختبارات اصطناعية وصور مرجعية لقياس أخطاء القص وتغيّر اللون.
5. تعديل يدوي للزوايا وفرشاة لمنطقة معينة وتصدير PDF للمستندات.
