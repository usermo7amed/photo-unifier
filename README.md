# مُوحِّد الصور (Photo Unifier)

تطبيق Android لتحسين الصور محليًا باستخدام Kotlin وOpenCV. يهدف إلى تحسين الإضاءة والتباين والتفاصيل مع الحفاظ على ألوان الصور ومحتواها الأصلي، من دون استخدام OCR لإعادة كتابة النصوص أو استبدال الحروف. تُحفظ النتائج في مجلد `Pictures/PhotoUnifier`، ولا تُعدَّل الملفات الأصلية.

## المزايا الحالية

- **معالجة مجموعة صور:** اختيار عدة صور، ومعاينة الصورة الأصلية والنتيجة، ثم حفظ النسخ المحسّنة.
- **تصنيف تلقائي محافظ:** يستخدم التطبيق نموذج ML Kit العام للتعرّف المبدئي على نوع الصورة، مع قواعد للثقة لتقليل اختيار مسار معالجة غير مناسب. التصنيف قد يخطئ؛ وعند ضعف الدليل يعود التطبيق إلى المعالجة العامة.
- **تحسين الصور وفق نوعها:**
  - **الصور الداخلية:** ضبط توازن الأبيض والإضاءة محليًا.
  - **الصور الخارجية:** تحسين الإضاءة مع مراعاة المناطق شديدة السطوع والحفاظ على ألوان المشهد.
  - **البوسترات:** معالجة أخف لتقليل التأثير على الألوان المقصودة.
  - **المستندات:** تقليل تفاوت إضاءة الورق على قناة الإضاءة مع الإبقاء على قنوات اللون، ثم تحسين التباين والتفاصيل.
- **الحفاظ على النصوص كما هي:** لا يستخدم مسار تحسين الصور OCR لاستخراج النصوص أو توليد الحروف من جديد. يجري التحسين على بكسلات الصورة نفسها، وليس على نص مستخرج؛ لذلك لا يُفترض أن يغيّر كلمات عربية أو إنجليزية عمدًا.
- **قص المستندات وتصحيح المنظور يدويًا:** من قسم معاينة الصورة، افتح «تحديد زوايا الورقة». يحاول التطبيق اكتشاف حدود الورقة تلقائيًا، ثم يعرض أربع نقاط قابلة للسحب ومعاينة للقص وتصحيح المنظور.
- **تعديل حدود القص:** سحب الزوايا، والتراجع عن التعديلات، وإعادة ضبط الحدود، أو إلغاء العملية وتطبيق القص. إذا تعذّر اكتشاف الورقة، يمكن ضبط الزوايا يدويًا.
- **ضبط السطوع والتباين:** تعديل النتيجة قبل الحفظ.
- **دعم الصور الكبيرة:** تُصغّر الصور التي يزيد طول ضلعها عن 4096 بكسل مؤقتًا لتقليل استهلاك الذاكرة أثناء المعالجة.

## طريقة استخدام قص المستند

1. اختَر صورة واحدة أو أكثر.
2. افتح قسم **معاينة الصورة** واضغط **تحديد زوايا الورقة**.
3. راجع الزوايا الأربع فوق الصورة، واسحب أي نقطة لتطابق حدود الورقة.
4. راجع **معاينة القص**. استخدم **تراجع** لاسترجاع آخر موضع، أو **إعادة ضبط** للرجوع إلى إطار الصورة الكامل.
5. اضغط **تطبيق القص**، ثم ابدأ التحسين. القص اليدوي يُطبّق على **الصورة الأولى المختارة فقط**؛ باقي الصور تتابع المعالجة المعتادة.

## الحفاظ على النصوص والألوان

- لا يعتمد مسار تحسين الصور على OCR، ولا يستبدل الكلمات العربية أو الإنجليزية بنص مولّد.
- تحسين التباين والحدة والإضاءة يغيّر قيم بعض البكسلات؛ لذلك قد يتغيّر مظهر حواف الحروف قليلًا، حتى مع عدم إعادة كتابة النص.
- لا يمكن استعادة تفاصيل محروقة بسبب السطوع الشديد أو تفاصيل غير موجودة أصلًا في الصورة بصورة موثوقة.
- الصور الفوتوغرافية تُعالج في مسار ملون؛ ولا يُفترض تحويلها إلى أبيض وأسود لمجرد احتوائها على كتابة.
- تُحفظ النتائج في مجلد منفصل، ولا يتم تعديل ملفات الصور الأصلية.

## حدود معروفة

- نموذج ML Kit المستخدم نموذج تصنيف عام جاهز، وليس نموذجًا متخصصًا مدرّبًا على فئات التطبيق. قواعد الثقة تقلل القرارات الضعيفة لكنها لا تمنع أخطاء التصنيف. خطة التدريب والاختبار للنموذج المخصص موجودة في `docs/on-device-classifier-plan.md`.
- اكتشاف حدود الورقة يعتمد على تقنيات OpenCV التقليدية، وقد يفشل مع الخلفيات المتشابهة أو الإضاءة الضعيفة أو الأوراق المثنية. عندها يمكن ضبط الزوايا يدويًا.
- القص اليدوي يتطلب أن تكون مكتبة OpenCV جاهزة. التحقق الهندسي من الشكل الرباعي لا يضمن وحده أن الزوايا تطابق حدود الورقة بصريًا.
- التحسين ليس OCR ولا أداة لاستعادة نص مطموس بالكامل؛ الهدف تحسين الصورة المرئية مع تجنّب إعادة إنشاء محتوى النص.

## البناء والاختبارات

المشروع يستخدم Java 17 وGradle 8.7 وAndroid Gradle Plugin 8.5.2. من جذر المشروع شغّل:

```bash
gradle testDebugUnitTest assembleDebug --no-daemon --stacktrace
```

يشغّل GitHub Actions البناء والاختبارات عند تشغيل سير العمل المهيّأ، ويمكنه رفع ملف APK كـ Artifact باسم `photo-unifier-debug`.

تشمل اختبارات وحدة القص التحقق من قبول المستطيل الصحيح ورفض الزوايا المتقاطعة والنقاط خارج الصورة والأشكال شبه المنعدمة. وتوجد اختبارات Python تركيبية لخوارزميات OpenCV:

```bash
pip install opencv-python-headless numpy
python -m unittest discover -s tools/prototype/tests -v
python tools/prototype/enhance.py input.jpg before_after.jpg --mode document
```

الأنماط المتاحة في النموذج التجريبي: `auto` و`interior` و`exterior` و`document` و`poster`. النموذج التجريبي لا يشغّل ML Kit؛ التصنيف التلقائي موجود في تطبيق Android.
