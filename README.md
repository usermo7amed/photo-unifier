# مُوحِّد الصور (Photo Unifier)

تطبيق أندرويد بيعالج دفعة صور بضغطة واحدة: ضبط الإضاءة والألوان وإظهار التفاصيل. التصميم الكامل في [`docs/DESIGN.md`](docs/DESIGN.md).

## النسخة الحالية (0.1)

اختيار صور ← تحسين تلقائي ← حفظ في `Pictures/PhotoUnifier`. الأصلية ما بتتلمسش.

خط المعالجة: ضبط White Balance من البكسلات المحايدة بس ← ضغط الإضاءة العالية ورفع الظلال محليًا ← CLAHE ← تقوية تشبّع خفيفة ← Unsharp خفيف.

> الصور بتتصغر مؤقتًا لو أكبر من 4096 بكسل في أطول ضلع.

## بناء الـ APK (من غير ما تثبّت أي حاجة)

1. اعمل Repository فاضي على GitHub.
2. من فولدر المشروع على الكمبيوتر:

```bash
git init -b main
git add .
git commit -m "Stage 1"
git remote add origin https://github.com/<حسابك>/photo-unifier.git
git push -u origin main
```

3. على GitHub افتح **Actions ← Build APK**. أول Push بيشغّله لوحده، ولو لأ اضغط **Run workflow**.
4. بعد ما يخلص (حوالي 5 دقايق)، نزّل الـ Artifact اسمه `photo-unifier-debug`، فك الضغط، وثبّت الملف `app-debug.apk` على موبايلك (فعّل التثبيت من مصادر غير معروفة لو طلب).

لو الـ Build فشل: افتح الـ Run، وانسخ آخر 30 سطر من سجل خطوة **Build debug APK** وابعتهم.

## تجربة الخوارزمية على الكمبيوتر

```bash
pip install opencv-python-headless numpy
python tools/prototype/enhance.py input.jpg before_after.jpg
```

بيطلّع صورة قبل/بعد جنب بعض وإحصائيات (متوسط السطوع، نسبة المناطق المحروقة). القيم في أول الملف هي نفس القيم في `Processor.kt`، فأي قيمة تعجبك انقلها مكانها.

## الخطوات الجاية (واحدة واحدة)

1. اختيار النمط: تلقائي / داخلي / خارجي.
2. أوراق: اكتشاف الحواف والقص وتصحيح الميلان.
3. إزالة ظل الورق وتبييض الخلفية.
4. Histogram Matching مع صورة مرجعية لتوحيد الدفعة.
5. تعديل يدوي: سحب الزوايا وفرشاة لمنطقة معينة.
6. تصدير PDF للأوراق.
